# 项目封面

本模板的封面属于 xuan jing 的莫比乌斯视觉系列。

个人后续项目可从 [品牌素材与生成说明](https://github.com/shanghe000/shanghe000/blob/main/assets/brand/README.md) 生成新的项目封面。使用模板的其他作者请换成自己的名字与视觉标识；项目初始化生成的 README 不会自动插入本模板封面。

README 使用本地 SVG。仓库分享图需在 Settings → General → Social preview 单独上传 PNG；建议 1280 × 640。头像、分享图与分支设置均不会随模板自动复制。
