# Project publication

New repositories and source imports start private. Use `scripts/new_project.py` for scaffolds; imports must explicitly adopt community files and publication checks.

Before release, run `scripts/check_repository.py`, `scripts/check_publication.py`, a full-history credential scan and the actual project tests. Replace scaffold prose with verified usage instructions. Do not publish internal work reports, machine paths, user data or deployment receipts. Preserve all required third-party attribution and confirm distribution rights.

Do not make a failed check pass by deleting tests, widening credential exceptions or rewriting integrity fingerprints without reviewing the underlying change. A template license does not automatically license imported source. Changes to visibility or published history require explicit task authorization.
